Cara Aktivasi

Ikuti langkah sesuai versi yang kamu beli.

Versi Online (Rp 199.000)

1

Buka app

Klik link versi Online yang diberikan setelah pembelian, atau bookmark dari sini.

2

Daftar / Masuk

Buat akun baru dengan email dan password, atau masuk kalau sudah punya.

3

Masukkan kode lisensi

Setelah login, akan muncul halaman "Aktifkan Lisensi". Paste kode dari atas, klik Aktifkan. Selesai!

+

Multi-device

Login di HP, tablet, atau laptop lain — data kamu sync otomatis lewat cloud.

Versi Offline (Rp 99.000)

1

Buka app

Klik link versi Offline yang diberikan setelah pembelian.

2

Masukkan kode lisensi

Langsung muncul halaman lisensi (gak perlu daftar). Paste kode, klik Aktifkan.

3

Install ke Home Screen

Biar kayak app beneran: di Chrome, tap menu (⋮) → "Add to Home Screen". App bisa dipakai tanpa internet.

!

Single-device

Data tersimpan di device ini aja. Jangan hapus data browser / clear cache, karena data bisa hilang. Rutin export backup dari menu Profil.

Panduan Fitur

Semua yang perlu kamu tau buat pakai Family Finance.

📊

Dashboard

Lihat total pengeluaran vs budget di halaman utama. Pilih periode: mingguan, bulanan, atau custom.

📁

Kategori

Bikin kategori pengeluaran (misal: Makan, Transport, Listrik). Set budget per kategori biar gak over.

💸

Catat Transaksi

Tap "+" buat catat pengeluaran. Pilih kategori, isi nominal, tambah catatan kalau perlu.

📈

Progres Budget

Tiap kategori ada progress bar. Hijau = aman, kuning = hampir limit, merah = over budget.

📅

Periode Fleksibel

Ganti tampilan ke mingguan, bulanan, atau tanggal custom. Budget otomatis dihitung proporsional.

💾

Backup & Export

Dari menu Profil, export data ke file JSON. Bisa di-import lagi kapan aja buat pindah device atau restore.

📱

PWA / Add to Home

Install ke home screen biar bisa dibuka kayak app native. Cepat, ringan, tanpa download dari Play Store.

🔒

Privasi

Versi offline = data 100% di device kamu. Versi online = data di cloud, cuma kamu yang bisa akses.

FAQ

Kode lisensi belum muncul?

Kode di-generate otomatis setelah pembayaran terverifikasi. Tunggu maksimal 5 menit, lalu cek ulang dengan email yang sama.

Bisa pindah dari Offline ke Online?

Bisa. Export data dari versi Offline (menu Profil → Export), lalu import di versi Online. Kode lisensi terpisah — perlu beli versi Online kalau belum punya.

Hapus cache browser, data hilang?

Versi Offline: ya, karena data di IndexedDB browser. Makanya rutin backup. Versi Online: aman, data di cloud.

Butuh bantuan?

Hubungi kami via WhatsApp di link yang ada di email konfirmasi pembelian.
